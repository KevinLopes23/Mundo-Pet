OPÇÃO 2: Manual (Passo a Passo)
────────────────────────────────────────────────────────────────────

1️⃣  Personalizar informações:
    • Substitua "seu-usuario" no README.md
    • Atualize email no SECURITY.md
    • Revise informações pessoais

2️⃣  Criar repositório no GitHub:
    • Acesse: https://github.com/new
    • Nome: Mundo-Pet
    • Descrição: Sistema de agendamento para petshop
    • Public ou Private (sua escolha)
    • NÃO adicione README, .gitignore ou license

3️⃣  Conectar e enviar código:
    git add .
    git commit -m "feat: projeto completo pronto para GitHub"
    git remote add origin https://github.com/SEU-USUARIO/Mundo-Pet.git
    git branch -M main
    git push -u origin main

4️⃣  Configurar GitHub Pages:
    • Settings → Pages
    • Source: main branch, / (root)
    • Save
    • Aguarde 2-5 minutos

5️⃣  Acessar sua aplicação:
    https://SEU-USUARIO.github.io/Mundo-Pet/
