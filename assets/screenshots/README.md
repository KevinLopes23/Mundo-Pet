# 📸 Screenshots

Esta pasta contém as capturas de tela do projeto.

## Estrutura

- `screenshot-desktop.png` - Tela principal (desktop)
- `screenshot-mobile.png` - Versão mobile
- `screenshot-modal.png` - Modal de novo agendamento

## Como atualizar

1. Abra `index.html` no navegador
2. Use ferramentas de screenshot (Win + Shift + S no Windows)
3. Salve nesta pasta com nomes descritivos
