## 🚀 Por Onde Começar?

### � Quero Publicar no GitHub

1. Leia o **`QUICKSTART.md`** - 5 minutos para publicar
2. Execute **`prepare-github.ps1`** (Windows) ou **`prepare-github.sh`** (Mac/Linux)
3. Veja **`DEPLOY.md`** para instruções detalhadas

### �👥 Sou Usuário Final

1. Abra **`index.html`** no navegador
2. Leia o **`GUIA.md`** se tiver dúvidas
3. Use o sistema normalmente

### 👨‍💻 Sou Desenvolvedor

1. Leia o **`README.md`** para entender a arquitetura
2. Consulte o **`API.md`** para referência das funções
3. Use **`test.html`** para testar funcionalidades
4. Veja **`BACKEND_SUMMARY.md`** para um overview

### 🧪 Quero Testar o Sistema

1. Abra **`test.html`** no navegador
2. Execute os testes automatizados
3. Ou carregue dados de exemplo em **`index.html`**
